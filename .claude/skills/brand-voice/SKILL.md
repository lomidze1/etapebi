# Brand voice — etapebi.com

This is a reference handbook. It does not write copy on its own — the `content-writer` agent does that, and it cites this skill.

## Persona

Giorgi Lomidze is a working specialist, not a marketing brand. He writes the way he speaks to a property owner on-site: formal, factual, calm. He explains the work without selling it.

- **Tone:** formal, plain, professional. Direct without being curt.
- **Posture:** expert by experience, not by claim. Show competence through specifics (dates, stages, building class), not adjectives.
- **Frame:** fact > emotion. Numbers and process beat feelings.
- **Energy:** calm. He never shouts and never hustles.
- **Audience:** property owners (`მესაკუთრე`) commissioning construction work, not casual readers.

## Vocabulary — DO use

These are the project-correct, official, or industry-standard terms. Prefer them every time.

| Term | Why |
|---|---|
| `მესაკუთრე` | Property owner. The actual relationship — owner of the construction. |
| `ნებართვა` | Permit (building permit). Official term. |
| `ეტაპი` | Stage. The 5-stage building process is the core unit of work. |
| `ოქმი` | Protocol / formal record. Each stage produces one. |
| `აღრიცხვა` | Registration / accounting. Used in `დოკუმენტური აღრიცხვა`. |
| `დოკუმენტური აღრიცხვა` | Documentary registration. The exact service name. |
| `საჯარო რეესტრი` | Public Registry. Where construction is officially logged. |
| `ნაგებობის კლასი` | Building class. Official Georgian construction code term. |
| `საკადასტრო კოდი` | Cadastral code. Use when referring to a specific parcel. |
| `ფოტოანგარიში` | Photo report. The deliverable. |
| `ეტაპობრივი მონიტორინგი` | Stage-by-stage monitoring. Describes the working method. |
| `ფიქსაცია` | Fixation (factual recording). Better than "documentation" when the act is what matters. |
| `სამოქმედო ზონა` | Service area. Used to describe geographic coverage. |

## Vocabulary — DON'T use

| Term | Why not | Use instead |
|---|---|---|
| `კლიენტი` | Too transactional. Reduces a building owner to a customer relationship. | `მესაკუთრე` |
| `დოკუმენტაცია` | Vague. Could be anything. | `დოკუმენტური აღრიცხვა` (when naming the service) or `დოკუმენტური ანგარიში` (when referring to the deliverable) |
| `ჩვენი გუნდი` | There is no team. Giorgi works as an independent specialist. | `ვმუშაობ` / `ვუზრუნველყოფ` (first person singular) |
| `ბაზრის ლიდერი` / `ნომერ პირველი` | Marketing claim, unprovable, off-brand. | Show competence through specifics: years of experience, project count, specific stages handled. |
| `უმაღლესი ხარისხი` / `100%-იანი გარანტია` | Empty superlatives. | Describe what's actually delivered (e.g., `საჯარო რეესტრის მოთხოვნებთან თანხვედრით`). |
| `მაგარი` / `სუპერ` / `კაი` | Slang. Off-tone. | Drop or replace with neutral wording. |
| `აქცია` / `ფასდაკლება` | Sales-promotion register. Doesn't fit a professional service. | Discuss pricing only as `ფასი დამოკიდებულია ობიექტის ტიპზე და ეტაპების რაოდენობაზე` or similar. |
| `სასწრაფოდ!` | Urgency manipulation. | If timing matters, state it factually: `ეტაპის დასრულებიდან 7 დღის ვადაში`. |
| `დააჭირე აქ` / `მეტი` | Vague link text, hurts SEO and a11y. | Descriptive link text: `მომსახურების სრული აღწერა`, `კონტაქტის ფორმა`. |

## Writing rules

1. **Sentences are short.** Aim for 15–20 words. Two clauses max.
2. **Active voice.** `მესაკუთრე იღებს ფოტოანგარიშს` not `ფოტოანგარიში გადაეცემა მესაკუთრეს`.
3. **First person singular.** Giorgi works alone. Use `ვმუშაობ`, `ვუზრუნველყოფ`, `ვაფიქსირებ` — never `ჩვენ`.
4. **Sentence case always.** Headings, buttons, nav, body. Never ALL CAPS, never Title Case.
5. **One idea per sentence.** Lists for multiples; em-dash (`—`) for parenthetical clarification.
6. **Dates as digits.** `15.09.2025` or `2025-09-15`. Never `მე-15 სექტემბერი 2025 წელს`.
7. **Numbers:** digits when ≥ 10 (`12 პროექტი`); spelled out only for poetic emphasis (rare). Stage numbers always digits (`1-ლი ეტაპი`, `მე-2 ეტაპი`).
8. **Em-dash spacing.** Spaces on both sides — like this. Hyphen is for compound words only.
9. **Exclamation marks: rare.** At most one per page, never doubled.
10. **No emoji. Ever.** Not in copy, not in headings, not in CTAs.
11. **Quotations:** use Georgian quotes `„გარე" "შიგნით"` (low–high typographic pair) when quoting — but quoting is rare on this site.

## Transformation examples (bad → good)

Read each pair. The right column is the brand voice. The left column is what to never write.

### 1. Hero / opening claim

- **არასწორი:** ჩვენი გამოცდილი გუნდი 24/7 თქვენი სამსახურში — დაგვიკავშირდით ახლავე!!!
- **სწორი:** ვუზრუნველყოფ მშენებლობის ყოველი ეტაპის ფიქსაციას — ფოტოთი, ოქმით, თარიღით.

### 2. CTA

- **არასწორი:** სუპერ აქცია — დაიქირავე ჩვენი სერვისი დღესვე!
- **სწორი:** მომსახურების შეკვეთა — ტელეფონით ან ემაილით.

### 3. Service description

- **არასწორი:** უმაღლესი ხარისხის დოკუმენტაცია გარანტირებულად, ყველაზე ხელსაყრელ ფასად ბაზარზე!
- **სწორი:** დოკუმენტური აღრიცხვა საჯარო რეესტრის მოთხოვნებთან თანხვედრით. ფასი დამოკიდებულია ობიექტის ტიპზე და ეტაპების რაოდენობაზე.

### 4. About / claim of authority

- **არასწორი:** მე ვარ ხაშურის ბაზრის ლიდერი მშენებლობის სფეროში
- **სწორი:** ვმუშაობ ხაშურში და საქართველოს მასშტაბით — სპეციალიზაცია მშენებლობის ეტაპების დოკუმენტურ აღრიცხვაში.

### 5. Customer relationship

- **არასწორი:** კლიენტი იღებს ყველაფერს რაც კი სჭირდება, ჩვენ ვზრუნავთ ყველაფერზე
- **სწორი:** მესაკუთრე იღებს ფოტოანგარიშს, ოქმს და ტექნიკურ დოკუმენტაციას — ერთ პაკეტში.

### 6. Process / start

- **არასწორი:** მოდი ერთად შევქმნათ მაგარი პროექტი — დაგვიკავშირდი!
- **სწორი:** მუშაობა იწყება ობიექტის დათვალიერებით და ნებართვის დოკუმენტების გადახედვით.

### 7. Pricing reference

- **არასწორი:** ხელმისაწვდომი ფასები სანდო პარტნიორისგან!
- **სწორი:** ფასი დამოკიდებულია ობიექტის ტიპზე და ეტაპების რაოდენობაზე — დაუკავშირდით კონკრეტული შეფასებისთვის.

## Reference paragraphs

These three paragraphs are calibration anchors. When in doubt, read them and match the register. They are short on purpose.

### Hero (homepage opening)

> მშენებლობის ყოველი ეტაპის დოკუმენტური აღრიცხვა — ფოტოთი, ოქმით, თარიღით. მესაკუთრე იღებს სრულ პაკეტს, რომელიც აკმაყოფილებს საჯარო რეესტრის მოთხოვნებს. სამოქმედო ზონა — ხაშური და საქართველოს მასშტაბით.

### About (personal positioning)

> გიორგი ლომიძე — დამოუკიდებელი სპეციალისტი მშენებლობის ეტაპების აღრიცხვაში. ფოკუსი ფაქტობრივ ფიქსაციაზეა, არა მარკეტინგზე. ყოველი ანგარიში მოიცავს ფოტომასალას, ეტაპის ოქმს და თანდართულ ნახაზებს.

### Services (what's delivered)

> მომსახურება მოიცავს ეტაპობრივ ფოტოანგარიშს, ოქმების მომზადებას და ტექნიკური დოკუმენტაციის სრულ აღრიცხვას. მუშაობა იწყება ობიექტის დათვალიერებით და ნებართვის დოკუმენტების გადახედვით. ეტაპის დასრულებისთანავე მესაკუთრე იღებს ფოტოანგარიშს, ოქმს და განახლებულ დოკუმენტაციას.

## When to deviate

These are guidelines, not laws. Deviate only when:

- A legal or technical term has no plain-Georgian equivalent that preserves precision (use the official term and define it once).
- A direct quote from a permit or registry document must be reproduced verbatim.
- Translating a specific construction-code reference would lose accuracy.

Never deviate to add marketing emphasis, urgency, or warmth that the brand doesn't actually claim.
